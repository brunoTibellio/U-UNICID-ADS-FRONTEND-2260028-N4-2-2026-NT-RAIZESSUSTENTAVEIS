# Melhorias identificadas na revisão do MVP

Este registro descreve diferenças observadas entre a versão anterior do repositório e a versão de finalização. Não atribui os pontos a uma devolutiva específica do professor, pois esse registro de feedback não foi incluído no material consultado.

| Antes, na versão anterior do repositório | Depois, nesta versão de finalização |
| --- | --- |
| README descrevia o projeto como feito apenas em HTML e CSS | README atualizado para HTML, CSS e JavaScript |
| Menu principal apresentava sete páginas de conteúdo | Navegação principal ampliada para dez páginas, com páginas de Projetos, Conteúdos e Mídia |
| Formulário dependia da validação HTML nativa e redirecionava diretamente | Validação personalizada com JavaScript, mensagens por campo e destaque dos campos inválidos |
| Não havia recuperação do que foi digitado no formulário | Rascunho recuperado com localStorage |
| Não havia controle de alto contraste persistido | Controle de alto contraste com preferência salva no navegador |
| Não havia busca/filtro de conteúdos | Página de Conteúdos com busca e filtro por categoria |
| Documentação listava apenas o escopo | README, escopo atualizado, plano de testes, diário de IA e orçamento de hospedagem |

## Pontos que continuam pendentes

- Executar o W3C Nu HTML Checker nas dez páginas principais e corrigir todos os erros encontrados.
- Testar navegação por teclado e contraste AA.
- Testar responsividade em celular e tablet.
- Confirmar o vídeo externo em diferentes navegadores.
- Confirmar a publicação após integrar a branch e testar todos os links online.
- Registrar prints de desktop e celular e os resultados reais dos testes.
