Orçamento de hospedagem

Comparação de plataformas e escolha da opção mais adequada à estrutura atual do site.

Comparação das opções

O projeto é um site estático feito com HTML, CSS e JavaScript, sem banco de dados ou servidor próprio. Por isso, a hospedagem precisa publicar arquivos estáticos com HTTPS e integração simples ao repositório.

🐙

GitHub Pages

Disponível para repositórios públicos no GitHub Free. Publica arquivos HTML, CSS e JavaScript diretamente do repositório e oferece endereço HTTPS.

Custo previsto para este projeto: R$ 0,00. Não exige contratar um servidor para o site estático.

Documentação oficial →
🚆

Railway

Plataforma flexível para aplicações e serviços. O plano Free oferece crédito limitado de uso; o Hobby tem valor base de US$ 5 por mês, aplicado como crédito de uso, e pode haver cobrança adicional conforme consumo.

Custo: variável conforme plano e recursos utilizados.

Escolha para o Raízes Sustentáveis

GitHub Pages é a opção recomendada para a versão atual. O site não utiliza backend, banco de dados ou processamento no servidor. Como o repositório é público e o conteúdo é estático, o GitHub Pages atende à necessidade de publicação HTTPS sem adicionar uma mensalidade de hospedagem. O Railway continua como alternativa caso o projeto passe a precisar de API, banco de dados ou serviços executados no servidor.

Esta justificativa considera a arquitetura atual do trabalho e os planos consultados em 07/11/2026. Valores e condições podem mudar; conferir as páginas oficiais antes de contratar qualquer serviço.
