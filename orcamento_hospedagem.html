Orçamento de hospedagem

Comparação técnica de plataformas e justificativa da opção mais eficiente e sustentável para a arquitetura do site.

Arquitetura Web Sustentável (Green Web)

Eficiência energética e custo zero para sites estáticos

O portal Raízes Sustentáveis foi construído utilizando exclusivamente HTML5, CSS3 e JavaScript puro executados diretamente no navegador do usuário, além de ilustrações vetoriais leves em formato SVG.

Por não exigir banco de dados relacional nem processamento contínuo em servidor dedicado, a hospedagem estática via CDN reduz o consumo de energia em data centers e elimina custos mensais de manutenção.

GitHub Pages

Disponível para repositórios públicos no plano GitHub Free. Publica arquivos HTML, CSS, JS e imagens diretamente da branch principal com certificado SSL/HTTPS automático e distribuição global por CDN.

Custo previsto para este projeto: R$ 0,00 / mês.

Alternativa para Expansão Backend

Railway

Plataforma voltada para containers, APIs Node.js/Python e bancos de dados. O plano Free oferece crédito limitado de avaliação; o plano Hobby custa a partir de US$ 5,00 mensais (cerca de R$ 28,00 a R$ 30,00 conforme câmbio) mais consumo de CPU e RAM.

Custo: variável conforme recursos de servidor alocados.

Decisão e justificativa para o Raízes Sustentáveis

O GitHub Pages é a opção escolhida e recomendada para a versão atual do projeto. Como o site é 100% estático e utiliza armazenamento local do navegador (localStorage) para demonstração do formulário e preferências de acessibilidade, o GitHub Pages entrega desempenho superior, HTTPS nativo e custo zero. O Railway permanece documentado como opção de escalabilidade futura caso o projeto incorpore um servidor backend real.
